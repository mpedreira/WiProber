Survey Wi-Fi coverage using your own floor plans and export projects in ESX format.

• Create projects with multiple floors and calibrate each floor plan.
• Record measurements at selected points with Stop-and-Go.
• Collect measurements along a route with Continuous mode.
• Add positioned text notes and photos.
• Import ESX projects and append local surveys while preserving untouched source archive entries.
• Export all floors together for further analysis in Ekahau.
• Optionally measure each point: iPerf3 and Internet throughput, latency and jitter, DNS, ping, TCP and HTTP tests and replayed HTTP scripts, over the Wi-Fi network only.
• Track roaming and outages along Continuous routes.
• Follow a survey guide that suggests the next point on a grid and shades measured areas by signal.
• Export performance results next to the ESX for your own analysis tools.

Requires Android 11 or newer. Android requires location permission and enabled location services to retrieve Wi-Fi scan results. You mark your position on the plan; nimWifi does not request GPS coordinates. For frequent measurements, disable Wi-Fi scan throttling in Android Developer Options.

Projects and measurements are stored locally. There are no ads, in-app purchases, accounts or analytics. Android system backups and storage providers chosen by the user may copy files off the device. Network tests are off by default; when enabled, they contact only the servers you configure (and speed.cloudflare.com for the default Internet test). Imported server settings and credentials are excluded from backups.

The application interface is in English. This version has no separate Wi-Fi scanner screen. Imported Wi-Fi and spectrum measurements remain opaque and read-only; nimWifi does not provide all editing features of Ekahau.
